🔒 US AI Card Payment — Setup Guide

Owner only. Ye page customer ko nazar nahi ayega.

⚠️ Status: SETUP MODE
Payment form ready hai (payment.js), lekin asal payments ke liye JazzCash merchant API keys chahiye.

Step 1: JazzCash Merchant Account

  1. JazzCash Business portal par jao: jazzcash.com.pk → Merchant/Business
  2. Merchant Account ke liye apply karo
  3. Apply karte waqt "API Access" zaroor mango (sirf hosted page nahi)
  4. Documents: CNIC, bank details, business proof

Step 2: API Keys Hasil Karo

JazzCash se ye 3 cheezein milengi:

  • Merchant ID
  • Password
  • Integrity Salt

Ye kisi ko mat dikhao — sirf mujhe (Muse) secure tareeqe se do.

Step 3: Main Integration Kar Dunga

  1. Keys milne par payment.js mein USAI_PAY.mode = 'live' karunga
  2. Cloudflare Worker par secure backend lagayega (keys server par, site par nahi)
  3. Test payment kar ke verify karenge
  4. Phir har "Pay" button par card form khulega!

Customer Kya Dekhega?

  • ✅ "🔒 US AI Secure Payment" — hamari branding
  • ✅ Card number, expiry, CVV fields
  • ✅ "💳 Pay Securely" button
  • ❌ JazzCash ka naam kahin nahi
  • ❌ Aapki details kahin nahi

Alternative: Agar JazzCash Merchant Na Mile

  • Keenu (keenu.pk) — Pakistani gateway, card payments
  • PayPro — Pakistani gateway
  • Dono ka process same hai — API keys lao, main laga dunga
